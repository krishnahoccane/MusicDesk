LabelDesk - Change log
======================

Music label management for independent labels. Licensed by MusicDesk.tech.
All notable changes, newest first. Versions follow Semantic Versioning.

Version 4.3.2 (2026-11-23)
==========================

Added
-----
  * Sign-up for artists and labels (off by default): "Create an account" on the sign-in page
    with a form for artists (artist name) and labels (label name, website). Turn it on during
    installation (step 6) or in Settings → General → Sign-up, and choose whether artists, labels
    or both may sign up. New accounts cannot sign in until an administrator activates them in
    Users; administrators are emailed for every sign-up and the person is emailed when approved.
    Artists get an artist account linked to their new artist profile; label sign-ups create an
    inactive sub-label that is activated with the account (the administrator chooses the
    account's role). Strong passwords, a bot trap and a limit of 5 sign-ups a minute.
  * Catalog → Labels: sub-labels and imprints under the main label, nestable (a label can be
    part of another), with code, contact, website, country and active/inactive status. Each
    release can be assigned to a label; the label name delivered to stores follows it. Labels
    with releases or sub-labels cannot be deleted. New permissions "View labels" and "Manage
    labels".
  * Deactivation needs an emailed code: after the administrator's password, MusicDesk.tech
    emails a one-time code to the email the license is registered to; the installation is
    deactivated only with that code. Offline activations still need only the password.
  * docs/musicdesk-portal-changes-4.3.2.md: what the MusicDesk.tech portal and license server
    need for this version.

Changed
-------
  * Backups pause from 30 days before the license expires (and while it is expired or
    suspended): "Back up now" and the nightly backup are turned off with an explanation until
    the license is renewed. Existing backups can still be downloaded.
  * The footer shows only the version (e.g. v4.3.2); the sidebar shows only your logo and label
    name; the sign-in and suspension pages no longer say "Powered by LabelDesk".

Fixed
-----
  * The account menu (top right) opened behind the page content.
  * On Settings → License, the Deactivate dialog could not be used: the dark backdrop covered it
    and blocked typing the password.
  * Messages meant for the sign-in page (for example "The license is active again. You can sign
    in.") were not shown.

Version 4.3.1 (2026-11-23)
==========================

Added — change the license key
------------------------------
  * Change license key on Settings → License: enter the new key and confirm your password. The
    new key is checked with MusicDesk.tech first; only when it is accepted is the old key
    released for this domain and replaced. Refused keys change nothing.
  * On the suspension page (no one can sign in there): "Administrator: use a different license
    key" asks for the new key plus the email and password of an active administrator allowed to
    manage the license. Nobody is signed in by it; on success the sign-in page opens. Limited to
    5 attempts a minute and logged.
  * The suspension page shows the actual reason when the installation was blocked by
    MusicDesk.tech rather than expired.

Added — add-ons (plugins)
-------------------------
  * Administration → Add-ons: upload add-ons downloaded from MusicDesk.tech, then activate,
    deactivate or delete them, like WordPress plugins. Packages must be signed by MusicDesk.tech
    (Ed25519 signature over every file); unsigned, changed or unsafe packages are refused before
    anything is extracted. Uploading a newer version updates an add-on in place.
  * Every add-on has its own license key (LDAD-…), verified with MusicDesk.tech for this domain
    and re-checked every hour. An add-on runs only while it is active and its key is valid; a
    revoked, suspended or expired key, or a domain removed from the main license, pauses it (its
    data is kept).
  * Add-ons can add pages, sidebar items, permissions, Settings tabs, sign-in buttons, /api
    routes and database tables. Developer guide: docs/plugins.md; signed builds with
    scripts/build-plugin.php.
  * Available add-ons: Bulk upload, REST API, Incoming webhooks, Single sign-on (SSO).

Changed — bulk upload is an add-on
----------------------------------
  * Bulk upload moved out of LabelDesk core into the Bulk upload add-on (addons/bulk-upload,
    add-on code bulk_upload). Catalog → Bulk upload appears only while the add-on is active with
    a valid key. Its access switches moved from Settings → Catalogue to their own tab, Settings
    → Bulk upload. The permission "Bulk upload artists and releases" (catalog.bulk_upload) now
    belongs to the add-on; roles keep it on upgrade, and on a new installation it is given to
    Label Manager and Artist Manager the first time the add-on is activated. Upload history
    (bulk_uploads) is kept.

Added — license enforcement and cloud media storage
---------------------------------------------------
  * No cron job needed: background work (hourly license check, queued jobs, media uploads every
    5 minutes, nightly backup from 02:00, clean-up) runs by itself after page loads, once at a
    time; status in Administration → System. Optional php artisan labeldesk:tasks:run.
  * Hard-wired licensing: server address, issuer, signing key and provider are constants
    (LicenseAuthority); the LICENSE_* .env settings are gone and ignored. The development
    provider only runs in tests or php artisan serve with APP_ENV=local.
  * Expiry policy: read-only from the expiry date for 10 days (sign-in allowed), then the
    application is suspended — no sign-in — until renewed. Hourly license checks; "I have
    renewed — check again" on the suspension page. Ribbons: expiring in 30 days (staff
    dashboards), expired (every page and the sign-in page, with the lock date; countdown on
    staff dashboards).
  * Media storage (Settings → Media storage): any number of storage destinations, each with its
    own enable/disable switch, account and folder — several Google Drives, OneDrive (personal),
    OneDrive for Business (Microsoft 365, organisation tenant), Dropbox, Zoho WorkDrive (all
    data centres) and FTP/FTPS. Every file is copied to every enabled storage. Per-release
    folders <Release title>_<UPC> with masters as <ISRC>.<ext> and artwork as <UPC>.<ext> in
    their original format (verified by size and checksum — MD5, SHA-1 or Dropbox content hash),
    automatic renames, optional removal of the server copy after N days (0 = 12 hours) only once
    every enabled storage holds a verified copy, with streaming back from a storage. A storage
    cannot be removed while files exist only there. Uploads run every 5 minutes.
  * License check failure alert: every failed license check emails the vendor (PHP mail(),
    subject "<domain> - license check failed") and posts domain name, error, whether the email
    was sent, and the server's public IP address to the vendor's webhook. No license key or
    token is included in either. The failure is also reported to the license server's security
    webhook (POST /report on MusicDesk.tech, at most once an hour per reason); if it answers
    lock (domain blocked or key revoked) the installation is suspended until a later license
    check succeeds.
  * Administration → System no longer lists the license check among the automatic tasks.
  * CHANGELOG.txt: plain-text copy of the full change history, included in the release package.
  * The original artwork file is now kept alongside the re-encoded display copy.
  * Server (MusicDesk-Frontend): tokens carry the signed expires claim and the response
    expires_at.

Fixed — installation on shared hosting
--------------------------------------
  * License activation failed with "License verification failed." on new installs: the .env
    template pointed at an old placeholder address (/api/v1/licensing) instead of
    https://musicdesk.tech/api/license/v1. The template is corrected and installs created from
    the old template are redirected automatically.
  * Clear errors when something other than the license server answers: a Cloudflare block (with
    the Ray ID), a wrong server address, or another HTTP error. New "Test connection to
    MusicDesk.tech" button in the installer and php artisan labeldesk:license:diagnose (dummy
    key only; shows the server's public IP).
  * Missing vendor/ or public/build/ shows an "upload is incomplete" page instead of a PHP fatal
    error; a root .htaccess + index.php make installs extracted into public_html safe; a hand-
    copied .env without APP_KEY gets one before installation.

Added — MusicDesk design system, sign-in designs, new installer
---------------------------------------------------------------
  * MusicDesk look (from the MusicDesk UI/UX guide): ink canvas with frosted-glass cards, white-
    alpha hairlines, volt/flare gradients, tinted status badges, mono table headers and
    eyebrows, Inter Tight + Instrument Serif accent + JetBrains Mono (bundled, no font CDN),
    soft page glow (volt for the label team, accent for artist accounts) and film grain. New
    default theme "MusicDesk", dark by default; light mode keeps the same recipes. Branded page-
    header eyebrows on every screen.
  * White-label: custom brand colours (dark-mode shades derived automatically), font choice,
    logo, dark-mode logo and favicon uploads (SVGs with scripts are refused), served without a
    storage symlink.
  * Five sign-in page designs — Spotlight, Split, Cover, Studio, Minimal — with editable
    headline, italic accent word, subtitle, form heading, note and cover image; previews for
    administrators.
  * New installation wizard: 0 license (with site address) → 1 server check → 2 database → 3
    Redis (optional, tested, choose cache/sessions/queue) → 4 SMTP (test email, or skip) → 5
    super admin → 6 full customisation with live preview → review with "Change" links → install.

Added — Milestone 10 (Commercial release) and artist accounts
-------------------------------------------------------------
  * Artist accounts: a new "Artist" role for artists' own logins, linked to one or more artist
    profiles. Artists see and edit only their own profiles, releases, tracks, credits,
    deliveries, contracts and earnings; everything else (other artists, label revenue, users,
    settings) is hidden or answers 404.
  * Bulk upload (Catalog → Bulk upload): artists and releases with tracks from Excel / CSV
    templates, check-before-import with row-level problems, optional creation of missing
    artists, upload history. Administrators always; the label team and artist accounts each have
    an on/off switch (Settings → Catalogue). *Now the Bulk upload add-on, see Unreleased.*
  * Import sales reports (Reports → Import sales reports): choose or create a period, upload,
    map and process distributor / store sales reports; recent imports across all periods.
  * Branded error pages (403, 404, 419, 429, 500, 503) that work without built assets.
  * Release packaging script (scripts/package-release.php) and guides docs/user-guide.md,
    docs/release.md.
  * Route security tests: every application route requires sign-in; guests are redirected;
    viewers are refused on management pages.

Changed / security — Milestone 10
---------------------------------
  * The private storage disk is no longer served by URL (storage/{path} route removed); private
    files are only served by LabelDesk controllers after permission checks.
  * ISRC and UPC duplicate checks always cover the whole catalogue (also for artist accounts)
    without revealing other artists' releases.
  * Royalty statements can be opened with payments.view (artist accounts, own artists only).
  * Indexes on royalty lines for revenue by store and by territory.
  * Dependency audit: composer audit and npm audit report no known vulnerabilities.

Added — Milestone 9 (Reports, backups, configuration, redesign)
---------------------------------------------------------------
  * New look: redesigned dashboard (welcome hero, quick actions, KPI cards, revenue / release /
    store charts, upcoming releases, "Needs attention", administration panel with license, user
    allowance and system health, activity timeline), sidebar, top bar and cards.
  * Themes: eight colour themes (Aurora, Ocean, Emerald, Sunset, Rose, Midnight, Graphite,
    Sand), three sidebar styles, and a light/dark policy (both, light only, dark only) with a
    default mode — chosen by the administrator in Settings → Appearance with live preview.
  * Global search (Ctrl/Cmd+K or "/") across artists, releases, tracks, contributors and users,
    respecting permissions and the license plan.
  * Reports: releases by status and date, catalogue gaps (missing audio / ISRC / credits), store
    deliveries, distribution by store, royalty revenue by period / artist / release / track /
    store / territory, artist balances (as of a date), artist payments, contracts ending soon.
    Filters, on-screen totals, CSV and Excel export, export log.
  * Backups: database (pure PHP, no mysqldump) and uploaded files in one ZIP, download, delete,
    retention, nightly schedule, labeldesk:backup command, restore guide (docs/backups.md).
  * Settings → Catalogue: label name, © / ℗ line formats, default language, genres and
    languages.
  * Administration → System: versions, server, database, storage, scheduler heartbeat, queue and
    email status; database upgrade button and labeldesk:upgrade command.
  * Licensing: connected to the production MusicDesk.tech licensing server (v1: activate, check-
    in, deactivate) with Ed25519 JWT verification, server messages, support-until and latest-
    version info, staging domains, automatic re-activation, and offline activation with request
    / .ldlic files.

Changed — Milestone 9
---------------------
  * users.theme is now nullable (NULL = not chosen) so the administrator's default mode applies.
  * Starter genre, language and store lists are seeded only once; upgrades no longer re-add
    entries the label deleted.
  * License keys use the LDSK-XXXX-XXXX-XXXX-XXXX format; plans are Starter, Business and
    Enterprise.

Added — Milestone 8 (Royalties)
-------------------------------
  * Royalty periods (non-overlapping; lockable after they end), with matched revenue, artist and
    label totals and unmatched amounts.
  * Statement imports: CSV (comma/semicolon/tab, auto-detected) and XLSX via OpenSpout
    (streamed), automatic column guessing, saved mapping profiles, decimal point or comma,
    currency with exchange rate, live preview of parsed amounts, duplicate-file protection,
    queued processing with a "Process now" fallback for hosts without cron, revert.
  * Matching by ISRC (original release preferred over compilations) or UPC; manual matching of
    unknown identifiers to a track, or "not ours".
  * Exact allocation: equal split between primary artists (rounding remainder to the last),
    artist share from the recording/distribution/license contract in force on the sale date,
    else the configurable default artist share; label commission is the remainder.
  * Artist accounts: earnings posted on lock, recoupable advances and expenses, payments (never
    above the balance), adjustments and reversals; artist balances page and artist Earnings tab.
  * Royalty statements per artist and period (on screen, printable, CSV and XLSX), provisional
    while open.
  * Dashboard royalty figures.

Added — Milestone 7 (Distribution)
----------------------------------
  * Store list (27 major DSPs seeded) with lead times, delivery notes, activate/deactivate and
    management screen (dsps.manage).
  * Release → Distribution tab: add stores (ready releases only), mark delivered (back-datable),
    mark live with store ID and link, store rejections and takedowns (reason required), cancel
    or confirm takedowns, bulk "mark delivered/live", remove pending stores, per-store history,
    lead-time warnings.
  * Business → Distribution overview: counts by status, filters by store and status, search, and
    releases that are ready but not sent anywhere; dashboard distribution figures.
  * Releases cannot be reopened while pending, delivered or live at any store.

Added — Milestone 6 (Music catalog)
-----------------------------------
  * Releases: list (search by title, artist, UPC or catalogue no.; status/type/genre filters),
    create/edit with ordered artist credits (primary/featuring/remixer), UPC checksum
    validation, ©/℗ lines, genre and language, square artwork (re-encoded, thumbnail), soft
    delete/restore while editable.
  * Tracks: per-release track list with disc/position ordering, ISRC validation and uniqueness
    (re-use allowed on compilations), artist credits, songwriter/producer credits with
    publishing shares (≤100% per role), explicit flag (release explicit follows its tracks),
    global Tracks list.
  * Master audio: WAV/FLAC uploads inspected from the file header (sample rate, bit depth,
    channels, duration; ≥44.1 kHz/16-bit), stored privately, streamed with range support and
    downloadable only with tracks.download_master (downloads logged).
  * Contributors directory (IPI, PRO) with inline creation from the track form.
  * Approval workflow: draft → submitted → in review → approved → ready for delivery, request
    changes with a required comment, withdraw, reopen; a completeness checklist gates submission
    and approval; content is locked outside draft; full status history.
  * Artist profile Releases tab; artists credited on releases or tracks cannot be deleted.
  * Reference data seeder (genres, languages); dashboard release figures.

Added — Milestone 5 (Artist management)
---------------------------------------
  * Artists: list with search, status/type/country filters, sorting and pagination; create/edit
    with photo upload (re-encoded to a clean JPEG); soft delete and restore; profile page with
    tabs for overview, contacts, links, contracts, documents and activity.
  * Contacts (one primary per artist), streaming/social links validated per platform (http/https
    only).
  * Contracts: type, status, term, artist royalty share (DECIMAL percent), advance
    (DECIMAL(18,6)) and currency; active contracts past their end date show as expired; Business
    → Contracts overview with an "ending within 60 days" filter and dashboard figures.
  * Private documents: stored under random names on the non-public disk, file type checked from
    content, size-limited, downloaded only through an authorised route (logged), optional link
    to a contract.
  * License features: artists gates the artist module; documents gates contracts and documents.
  * Upload limits configurable via LABELDESK_DOCUMENT_MAX_KB / LABELDESK_IMAGE_MAX_KB.

Added — Milestone 4 (Authentication & administration)
-----------------------------------------------------
  * Password reset by email with generic responses (no account discovery), throttling, active
    accounts only; resetting signs the user out everywhere.
  * My profile: name, email (current password required), theme and password change.
  * Users: search and filter by role/status, add (with an emailed set-password link or a chosen
    password), edit, deactivate, delete and restore, resend password link. The license user
    allowance is enforced on the server; there is always one active Super Admin; nobody can
    deactivate, delete or re-role themselves, or grant access they do not have.
  * Roles: built-in roles keep their names but their permissions are editable; custom roles
    require the custom_roles license feature; permissions grouped by module with select-all.
  * Settings: General (label name, timezone, currency, date/time format, language, log
    retention) and Email (SMTP/sendmail/log, encrypted password, test email), applied over .env
    at boot.
  * Activity log: sign-ins, failures, lockouts, user/role/settings changes; filter by event,
    user, date and text; expandable details; nightly pruning by retention period.
  * auth.session middleware so password changes end other sessions.

Changed
-------
  * Super Admin's Gate::before bypass now applies to permission checks only; model policies
    (e.g. "cannot delete yourself") apply to Super Admins too.
  * RolesAndPermissionsSeeder no longer re-grants permissions an administrator removed from a
    built-in role.

Added — Milestone 3 (Licensing)
-------------------------------
  * MusicDesk.tech licensing client: provider abstraction (MusicDesk, future Envato, development
    mock), HTTPS-only API client with idempotency keys, replay protection and HMAC request
    signing.
  * Ed25519-signed license tokens verified with an embedded public key; signed offline cache
    with a 14-day grace period, then documented read-only mode. Fails closed when not
    configured.
  * Feature entitlements from the license (canUse(), feature: middleware, locked navigation
    items).
  * Settings → License page: masked key, plan, expiry, activations, user allowance, features,
    history; Verify now, Deactivate (password confirmed), Transfer to new domain, re-activation.
  * Daily labeldesk:license:verify heartbeat and opportunistic refresh for hosts without cron.

Added — Milestone 2 (Installation wizard)
-----------------------------------------
  * Browser installer: welcome & terms, requirements check, database test (refuses non-empty
    databases), application settings, administrator, license activation, install, one-time
    completion page.
  * Automatic .env + application key creation on first visit; atomic, escaped .env writer.
  * Permanent installation lock outside public/; installer returns 404 once installed.
  * Interrupted installations resume safely; labeldesk:install:restore-lock recovery command.
  * Default roles (Super Admin, Label Manager, Artist Manager, Distribution Manager, Accountant,
    Viewer) and 41 permissions; settings store.
  * Installation guide (docs/installation.md) for cPanel and VPS.

Added — Milestone 1 (Foundation)
--------------------------------
  * Laravel 12 application with Livewire 3, Spatie Laravel Permission and OpenSpout.
  * Bootstrap 5 design system compiled from SCSS with CSS-variable design tokens.
  * Light, dark and system themes, persisted per user, applied before first paint.
  * Application shell: collapsible sidebar, mobile off-canvas navigation, top bar, breadcrumbs,
    toast notifications.
  * Reusable Blade components: icon (server-rendered Lucide), logo, page header, stat card,
    badge, alert, empty state, breadcrumbs.
  * Sign-in and sign-out with per-email+IP throttling, session regeneration and inactive-account
    blocking.
  * Security headers middleware.
  * Config-driven, permission-aware sidebar navigation.

Requirements: PHP 8.2+ (8.3 recommended), MySQL 8 / MariaDB 10.6+, a MusicDesk.tech license.
See docs/installation.md, docs/user-guide.md and docs/backups.md for details.
